## Architectural Principles

1. **Deterministic Foundations Over Stochastic Guarantees:** Critical decision boundaries, curriculum progression, and state transitions must be mathematically verifiable and unit-tested. Generative models belong strictly in the synthesis layer.
2. **Latency is a Core Constraint:** Human perception thresholds dictate software design. WebRTC media and duplex audio streaming must consistently operate under 250 milliseconds.
3. **Auditability and Modularity:** Clean isolation between state management, network transport, and user interface rendering to prevent cascading state invalidation.
